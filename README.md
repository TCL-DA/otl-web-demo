# OTL Roaster — 5 phương án giao diện mới cho otlpro.com

**Xem trực tiếp:** https://tcl-da.github.io/otl-web-demo/

Mỗi bản là một trang chủ demo dựng theo một phong cách thiết kế (thư viện [Refero Styles](https://styles.refero.design/)).
Chữ, thông số và ảnh đều lấy từ otlpro.com hiện tại — chỉ đổi cách trình bày.

| 3 | BMW.com | [Mở](https://tcl-da.github.io/otl-web-demo/3-bmw.html) | [Refero](https://styles.refero.design/style/b8899cbd-e2ca-4069-83cf-d8f8b0d71100) |

Mỗi bản có 5 sản phẩm kèm ảnh thật (OTL-06, OTL-03, máy tách đá OD, silo, xử lý khói AB), bảng 8 dòng máy,
menu điện thoại, form liên hệ (chỉ kiểm tra ô bắt buộc, chưa gửi đi đâu). Mỗi file HTML tự chứa ảnh.

Đây là bản demo để chọn hướng thiết kế, không phải web chính thức.
